# Hole.io Karachi - City Devourer (Android & 3D Web)

An authentic 3D Hole.io style arcade game set in Karachi, Pakistan. Built using Three.js, WebGL, and Capacitor for Android.

## Features
- **Authentic Karachi 3D Environment**: Mazar-e-Quaid, Empress Market, I.I. Chundrigar banking skyscrapers, DHA bungalows, Quetta Alamgir chai dhabas, Burns Road biryani degs, auto-rickshaws, and Pakistani truck-art Bedford trucks.
- **Controls**: Mobile virtual touch joystick, desktop keyboard (WASD/Arrows), and mouse drag.
- **Physics & Suction**: 6 growth levels with smooth suction and scale-down animations into the void.
- **AI Competitors**: 5 AI bot holes competing on a live leaderboard.
- **Custom Skins**: Truck Art Chamak, Sindh Ajrak, Sea View Emerald, Mazar White & Gold, Chundrigar Cyber Neon.
- **Audio & Haptics**: Procedural Web Audio API sound effects and music loop with Android vibration support.
- **Android Platform**: Capacitor Android project ready for compilation in Android Studio.
